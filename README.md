# D3 에이전트 — 1차 MVP (탐색 + 수집)

데이터 분석 에이전트 "D3"의 축소판 1차 목표 결과물. 어떤 주제든 같은 프로세스(탐색 → 수집)로 동작하는지 확인하기 위한 실험.

## 폴더 구조

```
research/{주제}/
  brief.md                 — 리서치 브리프 (핵심 질문, 가설, 확인된 주요 수치, 출처)
  candidate_datasets.json  — 후보 공공데이터 소스 목록과 접근 방법/상태

data/raw/{주제}/
  {데이터}.csv              — 실제로 수집한 원본 데이터
  collection_log.md        — 수집 시도 기록 (성공/실패, 방법, 특이사항)
```

## 현재 포함된 주제

- **health-obesity**: 한국 성인 비만율(1998~2024) — 질병관리청 국민건강영양조사(KOSIS Open API로 수집)

## 설계 배경

전체 설계안(6단계 파이프라인, 도구 매핑, 검토 사항 등)은 프로젝트 문서(`d3-agent-architecture.md`, Claude 프로젝트 "에이전트 만들기"에 보관)를 참고.

## 주의사항

- 공공데이터 API 키 등 민감정보는 이 저장소에 커밋하지 않는다. 필요 시 `.env`(gitignore 처리)로 로컬에서만 관리한다.
- 전처리·분석·시각화·보고서 단계는 아직 이 저장소 범위 밖 (의도적으로 미룸).
