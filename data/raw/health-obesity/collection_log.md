# 수집 로그 — 건강(성인 비만율)

**일시**: 2026-09-01

## 1차 시도 (자동 다운로드) — 실패

e-나라지표, KOSIS 웹페이지에서 원자료 파일 다운로드를 시도했으나, 두 사이트 모두 다운로드가 자바스크립트 함수 기반이라 단순 HTTP 요청으로는 원자료를 받을 수 없었음. data.go.kr 검색 페이지도 SPA(자바스크립트 렌더링)라 자동 크롤링으로 데이터셋 목록조차 확인이 어려웠음.

## 2차 시도 (KOSIS Open API) — 성공

스텔라 님이 kosis.kr에서 Open API 인증키를 발급받아 전달, 이를 이용해 KOSIS Open API로 실제 데이터를 수집함.

**탐색 경로** (KOSIS 통계목록 API로 카테고리를 따라 내려가며 찾음):
`보건(F)` → `국민건강영양조사(F_17)` → `건강행태(117_11702_A01)` → `만성질환(117_11702_B01)` → `비만(117_11702_B01_001)` → 테이블 **`ORG_ID=177`, `TBL_ID=DT_11702_N101`** (비만 유병률(체질량지수 기준) 추이)

**데이터 조회 API**: `Param/statisticsParameterData.do` (itmId=RATIO, objL1=ALL, objL2=101(19세이상), orgId=177, tblId=DT_11702_N101)

**받은 데이터**: 1998~2024년, 전체/남자/여자 3개 그룹 × 21개 연도(조사가 매년 실시되지 않은 해 제외) = 63행. 파일: `obesity_prevalence_1998_2024.csv`

## 확인된 데이터 특이사항 (분석 단계로 인계)

- 이 KOSIS RATIO 값은 **연령표준화하지 않은 원 유병률**로 보임. 앞서 탐색 단계 브리프에 적었던 e-나라지표 수치(2023년 표준화 기준 37.2%, 남 45.6%/여 27.8%)와 이번 KOSIS 원자료(2023년 37.1%, 남 44.0%/여 30.2%)가 소폭 다른데, 이는 연령표준화 여부 차이로 추정됨 → 분석 단계에서 "표준화 vs 비표준화" 중 어떤 기준으로 추세를 볼지 결정 필요.
- 조사는 1998, 2001, 2005년 이후 매년(2007~2024) 실시됨 — 2002~2004, 2006년 데이터 없음(결측 아니라 조사 미실시).
- 2020년(코로나19 시기) 전체 38.4%로 큰 폭 상승 후 소폭 등락 — 실제 알려진 보도 내용과 일치.

## 남은 과제 (범위 밖, 참고용)

- 연령대별(20대/30대/40대 등) 세부 데이터는 이번엔 받지 않음 — 필요시 같은 방식으로 추가 조회 가능.
- API 키는 이 세션 안에서만 사용했고 어떤 파일에도 저장하지 않음. GitHub repo를 만들 경우, 키는 `.env`(gitignore 처리) 등으로 별도 관리 필요 — 코드나 데이터 파일에 하드코딩 금지.
