# 수집 로그 — 1인 가구 비율

**일시**: 2026-09-02

## 시도 및 결과

건강 주제 때와 동일하게 KOSIS Open API를 사용. **이번엔 새 API 키를 발급받지 않고, 이전에 발급받은 키를 그대로 재사용** — 같은 세션 안에서는 키 하나로 여러 주제/여러 테이블에 재사용 가능함을 확인.

**탐색 경로**: 이번엔 KOSIS 100대 지표 페이지(웹서치로 바로 발견)에서 TBL_ID 힌트(`DT_1YL21161`)를 먼저 얻고, `ORG_ID=101`을 추정 검증하는 방식으로 진행 — 건강 주제 때보다 카테고리 트리를 덜 타고 더 빨리 찾음. 대조 확인차 KOSIS 통계목록 API로 인구(A) → 가구부문(A12) → 총조사가구(2015년 이후) → 1인가구 카테고리도 함께 확인함 (다만 그 경로에는 시군구 세분류 표만 있고 전국 시계열 표는 100대 지표 쪽에만 노출되어 있었음 — 카테고리 트리 탐색만으로는 못 찾을 수도 있다는 걸 알게 됨).

**수집 결과**: 2000, 2005, 2010, 2015년 + 2016~2025년(매년) 총 14개 연도, 전국 기준 1인가구 수·총가구 수·비율(%) → `one_person_household_ratio_2000_2025.csv`

## 재현성 관전 포인트 (건강 주제와 비교)

- **같았던 점**: KOSIS Open API 키 재사용 가능, `Param/statisticsParameterData.do` 호출 패턴 동일, 데이터 검증 방식(작은 표본으로 raw JSON 대조) 동일하게 적용
- **달랐던 점**: 이번엔 카테고리 트리를 끝까지 타지 않고 KOSIS 100대 지표 페이지에서 TBL_ID를 바로 얻어서 더 빨랐음 — "탐색" 단계에서 얻은 정보가 "수집" 단계 경로를 바꿀 수 있다는 뜻. 이번 데이터는 성별 등 하위 그룹 구분이 없어 건강 데이터보다 구조가 더 단순함(재구성/pivot이 필요 없음).
